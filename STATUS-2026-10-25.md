# Status correction — 25 October 2026

This file corrects the current-tense status of this repository. It is a separate file because `README.md`, `verify.py`, `CHANGELOG.md`, `LICENSE`, `examples/verify_expected.txt` and the other pack files are listed in `hash_manifest.json`; editing them would break the manifest. Whether to annotate the README and regenerate the manifest is an owner decision. Statements in the hash-covered files predate this correction.

- This is a first-party proof-of-concept evidence pack by VeritasChain Co., Ltd., which operates the VeritasChain Standards Organization (VSO). It targets VCP v1.1 (Silver tier). VCP v1.1 has no tagged release and is superseded by VCP v1.2 (Released, tag `v1.2.0`).
- Conformance to any VCP tier, or to VAP, has not been independently established. "VCP v1.1 Full Compliance" and the `FULLY COMPLIANT` / "fully compliant" lines printed by `verify.py` and quoted in the README are not results. There are zero external implementations of VAP or any of its profiles, including VCP.
- Not certified. VSO does not issue certifications itself. The certification scheme requires a Conformity Assessment Body (CAB) independent of the scheme owner; the only registered CAB, VeritasChain Co., Ltd., is not independent (VAP v1.2 ERRATA E-2026-10-21). The README line "For official VC-Certified status, contact: certification@veritaschain.org" is superseded by this rule. Conformance is not compliance (VAP v1.2 §1.6). In the README, the "Cryptographic Guarantee" column should read "Verification mechanism", and "Immutable audit trail" (SEC Rule 17a-4 row) should read "tamper-evident audit trail".

## Known limitations of this pack

- **Synthetic data.** `datasets/metadata.json` and `hash_manifest.json` classify the data as `SYNTHETIC_DEMONSTRATION`.
- **No signatures.** Signatures are not deployed (README: "Signature Verification | Not deployed"); the events carry `SignAlgo` in the header but no signature values.
- **No external anchor.** The only anchor in `anchors.json` is `AnchorTarget: "LOCAL_FILE"`. A local file is not an external anchor, so the pack does not meet the external-anchoring requirement (VAP v1.2 INT-006; VCP Silver), although `verify.py` reports "External Anchor REQUIRED ✓". The local anchor file it refers to (`anchors/anchor_20250106_001.json`) is not in the repository.
- **Event ID validity.** 24 of the 27 event IDs use a non-RFC UUID variant and are not valid UUIDv7 identifiers. Interpreting their leading 48 bits as timestamps does not establish UUIDv7 validity.
- **Dates may be mis-stated (2025 vs 2026).** Event times and `CHANGELOG.md` say 2025-01-06, but the first 48 bits of the event IDs, interpreted as Unix milliseconds, correspond to 2026-01-06T04:55:05.321Z or 2026-01-06T04:55:05.322Z, the anchor timestamp is 2026-01-06T04:55:05Z, and the pack cites VCP v1.1, which was published on 2025-12-30. The dates are not corrected because the files are hash-covered.
